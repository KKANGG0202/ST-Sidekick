# 소곤이 (관전 수다 패널)

책갈피 리본 꼬리를 단 꼬마 유령 소곤이가 채팅 옆 패널에 앉아, 지금 하고 있는 롤플레이에 대해 "채팅 밖에서" 같이 이야기해 주는 확장입니다. 캐릭터들은 소곤이를 보지도 듣지도 못합니다.
패널의 대화는 채팅창에 표시되지 않고, 롤플레이 프롬프트에도 들어가지 않습니다.

## 모드
- 자유 질문
- 🧭 상황 정리: 지금 무슨 상황이고 왜 이렇게 됐는지
- 💭 속마음: 캐릭터가 왜 이러는지 해석
- 🍿 덕톡: 같이 떠드는 수다 상대
- 💡 전개: 앞으로 이야기가 나아갈 큰 흐름 추천
- 🔀 스와이프 비교: 마지막 답변의 스와이프들 비교
- ⚖️ 비평가: 고정 기준 8개로 채점하는 냉정한 리뷰 (재미용, 조언 없음)
- 💊 처방전: 캐붕, 설정 충돌, 모순, 반복을 진단하고 붙여넣을 지시문 제공. 설정에 내 기준(싫어하는 단어 등)을 적으면 그것부터 검사
- 🩺 캐붕 체크: 한 답변이 캐릭터답게 나왔는지 빠른 판정
- 🔎 누구였지: 조연, 용어 빠른 설명
- 직접 만든 모드: 설정에서 칩 이름과 지시문을 적어 추가

말풍선 아래 눈 아이콘을 누르면 지우지 않고 소곤이한테만 숨길 수 있습니다. 답변 아래 압정으로 핀해 두면 패널 위의 압정 버튼으로 모아볼 수 있습니다.

입력 없이 전송하면 그 모드의 기본 질문이 나갑니다.

## 읽는 범위
캐릭터 AI가 기억하는 범위와 같게 맞춥니다.
- 숨김 처리되지 않은 메시지
- 다른 확장이 프롬프트에 주입하는 내용 (요약 확장의 요약, 작가 노트 등)
- 캐릭터 카드, 페르소나, 활성화된 로어북

## 특정 부분 물어보기
- 메시지의 `...` 메뉴에서 말풍선 아이콘: 그 메시지를 인용
- 채팅에서 문장을 드래그한 뒤 패널의 ❝ 버튼: 선택한 문장만 인용

## 책갈피
메시지의 `...` 메뉴에서 책갈피 아이콘을 누르면 그 메시지부터 최신까지를 집중해서 봅니다. 책갈피는 챗마다 하나이고, 다른 메시지에 꽂으면 옮겨집니다. 같은 곳을 다시 누르면 빠집니다.

## 설정
패널 위쪽의 톱니바퀴 아이콘. 연결 프로필을 고르면 롤플레이와 다른 모델로 답변받을 수 있습니다.
비워 두면 현재 메인 API를 씁니다. 빠른 모델 프로필을 따로 지정하면 고른 모드(기본: 덕톡)만 그 모델로 답합니다.

읽는 범위도 여기서 바꿉니다: 캐릭터와 똑같이(기본) / 최근 N개 / 약 N토큰까지 / 숨긴 메시지까지 전부 / 캐릭터 카드와 페르소나만.

답장이 오면 띠링 소리가 납니다. 기본은 패널을 안 보고 있을 때만 울리고, 설정에서 끄거나 항상 울리게 바꿀 수 있습니다.

## 저장
패널 대화는 채팅별로 채팅 파일의 메타데이터에 저장됩니다. 외부로 보내는 것은 선택한 API로 가는 요청뿐입니다.

## 설치
`data/<유저>/extensions/` 아래에 폴더째 넣고 새로고침. PC와 모바일 모두 지원.
